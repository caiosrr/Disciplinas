# Nonlinear Optics - List 1, Question 4

This repository contains the numerical simulations used in Question 4 of List 1.
The scripts solve coupled nonlinear optical equations with a fixed-step fourth-order Runge-Kutta method.

## Contents

- `q4a.py`: sum-frequency generation with an undepleted-pump comparison.
- `q4bcd.py`: second-harmonic generation, phase-sensitive amplification, and the limit of a vanishing fundamental seed.
- `q4e.py`: semiclassical SPDC model seeded by the vacuum energy in a 100 GHz bandwidth.
- `figures/`: plots generated by the scripts and used in the written solution.

## How to Run

Create a virtual environment, install the dependencies, and run the scripts:

```bash
python -m venv .venv
python -m pip install -r requirements.txt
python q4a.py
python q4bcd.py
python q4e.py
```

The figures are saved in `figures/`.

## Model

For sum-frequency generation with perfect phase matching, the normalized amplitudes obey

```text
da3/dz = i g a1 a2
da2/dz = i g a1* a3
da1/dz = i g a2* a3
```

For degenerate second-harmonic generation, the equations become

```text
da_w/dz  = 2 i g a_w* a_2w
da_2w/dz = i g a_w^2
```

The simulations use the dimensionless propagation variable `gz`.

For the semiclassical SPDC estimate, `q4e.py` uses physical units and computes
the coupling constant from the crystal length, beam area, pump power, refractive
indices, and the first-order quasi-phase-matched value `d_eff = 2 d33/pi`.
